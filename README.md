# Home

Andreea's apartment and home projects.

## Apartment
- `apartment/floor-plan.html`: 2D floor plan (draft, not measured). `floor-plan-screenshot.png` is a render of it.
- `apartment/apartment-3d.html`: 3D planner of the empty apartment built from that plan. Open it in a browser to place furniture, change floor and wall colours and pin notes. Designs save in the browser and can be exported/imported as JSON.

Listing details and photos are kept locally only (git-ignored).
